# Zomato Sales & Business Analytics

## Project Overview

This project analyzes Zomato order and delivery data using SQL and
Power BI to identify patterns in sales performance, restaurant
performance, delivery operations, customer ratings, payment behavior,
and customer tipping.

## Business Objective

The objective of this project is to transform raw transactional data
into actionable business insights using SQL-based analysis and an
interactive Power BI dashboard.

## Tools & Technologies

- Excel
- MySQL
- SQL
- Power BI
- DAX

## Key Analysis

- Overall revenue and order performance
- City-wise revenue analysis
- Top restaurants by revenue
- Delivery-time analysis
- Delivery distance analysis
- Customer rating analysis
- Payment method analysis
- Order-status analysis
- Customer tipping behavior
- High-volume restaurants with low ratings
- Delivery distance vs delivery time correlation

## Key Findings

- Revenue and order volume vary across cities.
- Restaurant performance differs across revenue,
  order volume, and customer ratings.
- Delivery performance varies across cities and time categories.
- The calculated correlation between delivery distance and
  delivery time was approximately -0.005.
- High-volume restaurants with lower ratings can be investigated
  for customer-experience issues.
